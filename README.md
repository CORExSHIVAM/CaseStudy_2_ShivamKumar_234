# Case Study 2: Credit Card Fraud Detection

## Objective
The objective of this case study is to detect fraudulent credit card transactions using machine learning.

## Techniques Used
- Data Preprocessing
- Handling Class Imbalance
- SMOTE Oversampling
- XGBoost Classifier
- Decision Threshold Tuning
- ROC-AUC Evaluation
- Feature Importance Analysis

## Dataset
Credit card transaction dataset containing legitimate and fraudulent transactions.

## Model
XGBoost Classifier

## Evaluation Metrics
- ROC-AUC
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion
The XGBoost model was used to identify fraudulent transactions while SMOTE was applied to handle class imbalance. Different decision thresholds were evaluated to balance fraud detection and false positives.
